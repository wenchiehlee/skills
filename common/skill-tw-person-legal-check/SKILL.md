# 台灣人物法律查核技能 (tw-person-legal-check)

| 項目 | 內容 |
| :--- | :--- |
| 版本 | 1.0.0（詳見 `metadata.json`） |
| 登錄庫 | https://github.com/wenchiehlee/skills （`common/skill-tw-person-legal-check`） |
| 維護者 | wenchiehlee |
| 依賴技能 | `skill-tw-court-records-search`（裁判書查詢層——本技能在其結果上做身分脈絡建構、新聞佐證與風險分級，不重複實作查詢邏輯） |

本技能是 `skill-company-reputation-research` 的「人物版」——聚焦法律/訴訟曝險而非整體雇主評價；同時也是 `skill-tw-court-records-search` 的上層應用。使用前若尚未安裝 `skill-tw-court-records-search`，先取得該技能。

## Inputs

必要：

- 人名

建議提供以提高比對準確度：

- 職稱/任職公司（尤其是要查核公司負責人/經營層時）
- 年齡/地區等其他可比對資訊
- 若是從一篇新聞得知此人物，提供新聞連結或全文

## Workflow

1. **建立人物識別脈絡**
   - 全名、常見別名/曾用名（如有）
   - 目前/曾任職公司、職稱
   - 若為上市櫃公司經營層，記錄公司統編/股票代號，供後續比對重大訊息

2. **裁判書/訴訟查詢**
   - 呼叫 `skill-tw-court-records-search`，帶入姓名 + 步驟1的輔助識別資訊
   - 取得附信心分級的裁判書查詢結果表，直接沿用，不重新設計查詢邏輯

3. **新聞與公開資訊佐證**
   - 搜尋「姓名 + 起訴/判決/涉訟/背信/掏空/內線交易/違反證交法」等關鍵字
   - 若為上市櫃公司經營層，查詢公開資訊觀測站（MOPS）重大訊息是否有相關揭露（如假處分、假扣押、經營權訴訟、遭起訴公告）
   - 交叉比對新聞內容與步驟2的裁判書查詢結果，確認是否指向同一案件

4. **風險分級**
   - **高**：有明確指向此人、且已進入司法程序（起訴/一審以上）的訴訟或裁判紀錄，案由涉及背信/詐欺/掏空/證券違規等重大經濟犯罪
   - **中**：有民事訴訟紀錄（如債務糾紛、契約爭議），或案由不明確但同名+輔助資訊部分相符
   - **低**：僅有同名裁判書但輔助資訊不相符/無法比對，或僅有未經證實的新聞傳聞
   - **無明顯風險**：查無相關公開紀錄——需註明搜尋範圍與限制，不得宣稱「保證乾淨」

## Output Format

繁體中文報告，包含：

1. `人物識別` — 姓名、別名、任職公司/職稱、比對依據
2. `裁判書查詢結果` — 沿用 `skill-tw-court-records-search` 的表格格式
3. `新聞與公開資訊佐證` — 來源、日期、摘要，以及與裁判書查詢結果的對應關係
4. `風險分級` — 分級 + 理由 + 不確定性說明
5. `引用來源` — 全部連結，標明是否已驗證原文

## Evidence Rules

- 全部沿用 `skill-tw-court-records-search` 的規則：不得繞過驗證碼、不得還原依法遮蔽的個資、不得將「被告」等同「有罪」、「同名不確定」須明確標註。
- 本報告**非正式徵信/良民證文件**，需在報告中註明「僅供內部參考，非正式法律或徵信文件，正式用途請洽律師或申請良民證/警察刑事紀錄證明」。
- 不得公開傳播涉及未確定案件的指控性結論；僅整理已公開資訊並標註來源。
- 未進入司法程序、僅為網路傳聞或未具名指控的內容，須明確標註為「未經證實」，不得納入風險分級的「高」或「中」等級。
