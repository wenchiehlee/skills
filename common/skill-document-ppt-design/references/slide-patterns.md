# Slide Patterns

每個頁型對應一種訊息結構。從下表選定後，再依 `style-system.md` 套用對應風格的色彩與幾何語言。

---

## 1. Cover（封面）

**用途**：簡報開場，建立視覺基調。

**結構**：
- 主標題（大字，左對齊或略偏中）
- 副標題 / 日期 / 受眾標記（小字，style-specific 位置）
- 風格識別元素（accent 色條、插畫、和紙背景…）
- 風格的 signature 幾何 / 紋理

**規則**：
- 避免在封面放超過 2 行文字以外的內容
- Futuristic Tech：含 subtle grid overlay + coordinate marker
- Japanese Lifestyle：edge-aligned photo crop 可選
- Washi Paper：soft glow 光暈可選

---

## 2. Asymmetric Thesis（非對稱論述）

**用途**：簡報的核心主張頁。

**結構**：
- 短論點（大字，1–2 行）
- 3 個支撐証據（小型結構化模組）
- Accent 色僅用在最重要的詞或數字
- 至少保留 1/3 頁面為空白

**規則**：
- 避免使用條列（bullet list）；改用標籤化區塊
- 一頁只保留一個清楚論點

---

## 3. Data Signal（資料信號）

**用途**：以單一指標或數據為主角。

**結構**：
- 大字數字 / 標籤（Hero element，佔頁面約 25–35%）
- 細軸線、刻度、直接標籤
- 一條 accent 色高亮線或 bar
- 短洞察句（8–16 字，非整段段落）

**規則**：
- 圖表必須直接標籤，不用圖例
- Blue / accent 標記最關鍵的數據點，其餘用石墨色

---

## 4. System Map（系統圖）

**用途**：架構、平台、工作流程、供應鏈解釋。

**結構**：
- 由左至右或放射狀系統圖
- 細線連接器（hairline）
- 節點用短技術名詞標記
- Accent 色標示活躍路徑或瓶頸點

**規則**：
- 連接器不超過 2 px
- 節點數量不超過 7 個（超過時合併 / 分層）
- 不用文字框包住每個節點（改用 label-only）

---

## 5. Editorial Comparison（編輯式比較）

**用途**：Before/After、舊模型 vs 新模型、兩種策略比較。

**結構**：
- 不等分分割畫面（40/60 或 35/65）
- 石墨色代表基準 / 現況，accent 色代表目標 / 未來
- 避免重表格邊框；欄位稀疏、高可讀性

**規則**：
- 兩欄保持視覺平衡，不要一欄塞滿、一欄空白
- 不超過 5 個比較項目

---

## 6. Timeline Rail（時間軸）

**用途**：路線圖、事件序列、季度規劃。

**結構**：
- 水平或垂直軌道，小刻度點
- 當前或決定性里程碑用 accent 色高亮
- 短標題 + 粗間距
- 避免裝飾性里程碑圖示

**規則**：
- 時間節點數量不超過 8 個
- 每個節點只保留 2–3 行說明

---

## 7. Quote / Evidence（引言 / 佐證）

**用途**：強調市場數據、用戶回饋、外部觀點。

**結構**：
- 引言文字（大字，18–28 px，weight 300–400）
- 來源標記（小字，右下或底部）
- 簡單垂直或水平分隔線
- 不用引號圖示

**規則**：
- 引言長度不超過 35 字
- 不加背景色塊，只用留白分隔

---

## 8. Closing Signal（結尾信號）

**用途**：最終 takeaway，行動呼籲，或結語。

**結構**：
- 強結語一句（大字，30–44 px）
- 最少化支撐線（可選）
- 大量留白
- 小型 accent 色 marker 或 terminal-like 座標細節

**規則**：
- 結尾頁的文字量不超過封面
- 不重複條列前頁所有重點

---

## 頁型選型速查

| 內容形狀 | 建議頁型 |
| :--- | :--- |
| 開場設定 | Cover |
| 核心主張 | Asymmetric Thesis |
| 關鍵數字 / 圖表 | Data Signal |
| 架構 / 流程圖 | System Map |
| 兩方對比 | Editorial Comparison |
| 時程 / 里程碑 | Timeline Rail |
| 外部佐證 / 引言 | Quote / Evidence |
| 結尾 / 行動 | Closing Signal |
