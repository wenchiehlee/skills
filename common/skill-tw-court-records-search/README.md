# skill-tw-court-records-search

依人名、公司名或一篇新聞的內容，查詢台灣公開的裁判書/訴訟紀錄，並附上身分比對信心與審級/確定狀態。詳細查詢流程與輸出契約見 [SKILL.md](SKILL.md)。

這是一個純查詢/彙整技能，沒有可執行腳本——查詢動作由 agent 依 SKILL.md 的流程，透過搜尋工具（WebSearch/WebFetch）或瀏覽器工具實際操作司法院裁判書查詢系統來完成。需要完整的人物法律查核報告（含風險分級）時，改用建立在本技能之上的 `skill-tw-person-legal-check`。

## 快速開始

在對話中提供：

- 人名（常見姓名請附上職稱/公司/地區等輔助資訊）
- 或一篇新聞連結/全文

即可觸發本技能查詢並輸出結果表。

## 檔案結構

```
skill-tw-court-records-search/
  SKILL.md              # 技能指令與輸出契約
  metadata.json         # 版本與來源 metadata
  self_update.py         # 通用技能自我更新工具（跟其他skill共用同一份，勿修改）
```
